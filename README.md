# 接続表現の分布分析：租税法学論文の集計スクリプトと判断の記録

租税法学の論文で文頭に置かれた接続表現の分布を調べるための、本文の作成と集計のスクリプトです。版ごとに、それを使った論文と対応させています。

- v1.0：論文「租税法学論文における接続表現の分布と直接引用前後の用法」（掲載誌・号は未定）。DOI: [10.5281/zenodo.23860793](https://doi.org/10.5281/zenodo.23860793)

全版をまとめて指す DOI は [10.5281/zenodo.23860792](https://doi.org/10.5281/zenodo.23860792) です。

この版には、論文の数字を出すのに要る工程だけを置いています。

対象の論文の本文・PDF・頁画像は、著作物なので入れていません。動かすには、利用者が自分で PDF を入手し、本文を用意する必要があります。

## 対象

`data/targets.csv` に、対象 305 本の ID・誌名・号・年・形式・開始頁（『税法学』のみ。税大 2 誌は未確認）と、集計に使った本文の SHA-256 を載せています。題名と著者名は載せていません。

| 誌名 | 本数 | 形式 | 年 |
|---|---|---|---|
| 税法学（日本税法学会） | 145 | 論説 124、判例研究 21 | 2015〜2023（573〜589 号） |
| 税大論叢（税務大学校） | 122 | 論文 | 2015〜2023 |
| 税大ジャーナル（税務大学校） | 38 | 論説 31、裁決評釈 7 | 2015〜2023 |

税大 2 誌は、『税法学』の刊行年に合わせて選び（`scripts/02_select_nta.py`。論叢 123 本、ジャーナル 50 本）、文字層のない画像 PDF（ジャーナル 12 本）と、文字層で漢字の多くが欠けている 1 本（論叢 83 号の core4-0852。漢字の比率 19%、ほかは 36〜57%）は含めていません。

## 工程とスクリプト

| 工程 | 内容 | スクリプト |
|---|---|---|
| ① 入手 | 税大論叢の HTML・PDF、税大ジャーナルの PDF を保存する。『税法学』の PDF は日本税法学会のサイトで公開されているものを使った（保存に使ったスクリプトは残っていない） | `01_fetch_documents.py`、`01b_fetch_ronsou_pdfs.py`、`02_select_nta.py` |
| ② 文字の取り出し | PDF の文字層を、字の大きさと座標つきで読む（poppler の `pdftohtml -xml -i`） | ③のスクリプトの中で行う |
| ③ 本文の作成 | 税大 2 誌: 柱・頁番号・注・目次・参考文献を規則で除き、二段組みを左段→右段に並べる。『税法学』: 本文を作ったあと、字の大きさと座標で脚注の行を機械的に除く | `03_nta_pdf_to_body.py`、`04_zeihougaku_footnote_mask.py`、`05_check_mask_outputs.py` |
| ④ 画像との照合 | 頁画像と本文の行を照らし、見出し・注・柱の混入、欠け、段の順を直す | `06_page_images.py`（頁画像の作成と照合の記録。照合そのものは人と AI が行った） |
| ⑤ 判定 | 本文を文に切り、文頭の接続表現を辞書で探し、位置と判定を付ける | `connectives/recount_core.py`、`connectives/counting.py`、`09_build_corrections.py`、`10_count.py` |
| ⑥ 集計・検定 | 千字率・100 文率・6 分類の構成比・語形別、5 等分の位置、符号検定、長さ 3 群、直接引用の前後、漢字書きの別感度 | `20_rates.py`、`21_position_sign_test.py`、`30_c1_and_numbers.py`、`10_count.py --kanji9` |
| ⑦ 出力 | 表（CSV）と、論文に出てくる集計値（JSON） | 各スクリプトの出力 |

スクリプトは `scripts/` にあります。`90_export_dictionary.py` は辞書の定義を `data/dictionary.json` に書き出します。

## 動かし方

- Python 3.11 以上（作業は 3.14.7 で確かめた）。標準ライブラリだけを使います（`requirements.txt` 参照）。
- poppler 26.07.0（`pdftohtml`・`pdftotext`・`pdftoppm`・`pdfinfo`）。③④で使います。
- 作業時に使った Python・poppler 以外の道具の版は未確認です。

データの置き場所は環境変数か設定ファイルで指定します。`config.example.toml` を `config.toml` に写して書き換えるか、環境変数を使います。

| 環境変数 | 設定ファイルの鍵 | 内容 |
|---|---|---|
| `KIYO_DATA_DIR` | `data_dir` | 本文の置き場所。`data/targets.csv` の「本文ファイル」列（例 `bodies/zeihougaku/core4-1320.txt`）はここからの相対パス |
| `KIYO_CORRECTIONS_DIR` | `corrections_dir` | 補正入力の置き場所（`<zeihougaku または nta>/<ID>.json`）。省略時は `KIYO_DATA_DIR/corrections` |

```sh
export KIYO_DATA_DIR=/path/to/data
python3 scripts/09_build_corrections.py            # 判断の記録から補正入力を作る
python3 scripts/10_count.py --journal zeihougaku --out out/zeihougaku
python3 scripts/10_count.py --journal nta --out out/nta
python3 scripts/20_rates.py --in out/zeihougaku out/nta --out out/rates
python3 scripts/21_position_sign_test.py --in out/zeihougaku out/nta --out out/position
python3 scripts/30_c1_and_numbers.py --count out/zeihougaku --c1 <引用と文IDの対応表.csv> --out out/numbers
```

本文の SHA-256 が `data/targets.csv` と一致しないと、`10_count.py` は止まります。

補正入力（ID ごとの JSON）は、`data/decisions/` の判断の記録から `09_build_corrections.py` で作ります。本文の元の位置（オフセット）だけを持ち、本文の文字列は持ちません。

直接引用の前後の集計（`30_c1_and_numbers.py`）には、直接引用ごとに引用の種別と前後の文の文 ID を書いた対応表が要ります。この表はリポジトリには入れていません。

## 数える規則

規則は `connectives/recount_core.py` の中に定義があり、スクリプトはそれを直接使います。辞書を別のデータファイルにしなかったのは、判定の規則（`rule_status`）が語ごとの例外を Python の条件で持っており、辞書だけを外に出すと規則と辞書が別々に変えられてしまうためです。読むための控えとして `data/dictionary.json` を置いています（スクリプトはこのファイルを読みません）。

- 辞書: 6 分類（添加・並列、逆接・対比、説明・換言、補足・留保、理由・帰結、順序・継起）の 54 語形と、短形「これに対し」。表記の揺れ（「たとえば／例えば」など）は 1 つの語形にまとめる。このほか「むしろ」を添加・並列に、「けれども」を逆接・対比に入れる。
- 別枠: 「そこで」「この点」「このように」など 19 の定型複合表現は、辞書と同じ判定をしたうえで主集計には入れない（「むしろ」を除く）。
- 文: 句点・感嘆符・疑問符（引用符の内側を除く）と見出しの位置で切る。
- 位置: 文の先頭（開き括弧・閉じ括弧だけを前に置くものを含む）を「狭義文頭」とし、主集計は狭義文頭だけ。
- 分母: 地の文を含む文の、引用符の内側を除いた字数（句読点・引用符を含む）。

適用件数は、このリポジトリのコードを `data/decisions/` の補正入力で動かした値です（主集計 8,004／16,675／2,106 件、地の文 2,300,499／5,592,662／660,735 字）。

| 規則名 | 内容 | 適用件数（税法学／税大論叢／税大ジャーナル） |
|---|---|---|
| rule_main | 位置の条件に当たり、引用の外で、以下の除外に当たらないものを主集計の候補とする。狭義文頭のものを主集計に入れる | 主集計 7,990／16,667／2,104。節頭 2,104／4,579／750 と節末 479／1,421／165 は主集計に入れない |
| rule_quote | 引用符（「」『』“”）で示された直接引用の内部の語は数えない。引用符の対は、本文の中で対応のとれた組とする。記号のある引用で、組が機械的に成立しなかったものは位置を補う（引用符の対の補完）。引用符のない引用は地の文として扱う | 5,067／11,818／1,226（対の補完 5 区間を含む） |
| rule_eight | 並列の 8 表記（及び・および・又は・または・並びに・ならびに・若しくは・もしくは）は文頭でも主集計に入れず別掲とする | 4,147／16,013／1,188 |
| rule_katsu_head_only | 「かつ」「あるいは」は狭義文頭のものだけ主集計に入れ、文中のもの（読点の直後を含む）は別掲とする | 主集計 14／8／2、別掲 842／1,450／239 |
| rule_partial | 接続表現でない用法を、前後の字の形で除く（「かつて」「ただし書」「その一方当事者」「そのための」「によって」「次に掲げる」「ひとまず」「最も多い」「とはいえない」「なおかつ」など。条件は `rule_status` に列挙） | 非接続 2,069／4,713／445、辞書外の複合語 8／4／0 |
| rule_position | 文頭・節頭・節末のどれにも当たらない（文中の）ものは数えない | 1,455／2,810／371 |
| そのために_後続語修飾 | 文頭の「そのために」が直後の語句を修飾して名詞句の一部になっているときは、接続表現として数えない。決められないものは数える | 3 誌の 38 件に当て、数えないもの 0／2／0、決められないため数えるもの 0／1／0 |
| 見出し | 『税法学』は行の型（「はじめに」「おわりに」、Ⅰ・一・１ などで始まる 65 字以下で句点のない行、柱、頁番号）で見出しを除く。税大 2 誌は頁画像と照らして決めた見出しの位置で文を区切る | 税大 2 誌の見出しの位置 11,684 |
| 地の文の扱い | 他者の文章の再掲と確認できない部分は、著者の地の文として数える | — |
| 結びの節 | 論文の最後の節で、見出しが結びを示す語（「おわりに」「終わりに」「結び」「むすび」「結語」「結論」「まとめ」など）のものを結びの節とする。「4 語の結び除外」は見出しが「おわりに」「結び」「むすび」「結語」のどれかを含むものに限る。実際の見出しの語の一覧は `21_position_sign_test.py` が `結びの見出し語.csv` に書き出す | 結びの節あり 281 本、なし 24 本 |
| 漢字書きの別感度 | 「更に・従って・但し・尚・即ち・又・然し・故に・先ず」を仮名書きと同じ語として数え、除外の規則も仮名書きのものを当てる。主集計には入れない（8,144／16,954／2,139 件） | `10_count.py --kanji9` |

## 判断の記録

`data/decisions/` に置いています。本文の文字列は入れていません。位置は本文の元の位置（0 始まり、終わりの位置は含まない）です。頁は PDF の頁の順番で、記録にないものは空欄です。「確かめた者」は「人」か「AI」で、規則による機械の判定は空欄です。

| ファイル | 種類 | 内容 | 件数 |
|---|---|---|---|
| `a_出現ごとの判定.csv.gz` | 規則の適用 | すべての出現（主集計に入らないものを含む）の位置・表記・分類・文の中の位置・判断・規則名（gzip で圧縮した CSV） | 90,168 |
| `a_引用符の対の補完.csv` | 規則の適用 | 引用符の対の補完の区間（全角のカギ括弧 2、半角のカギ括弧 2、ASCII の二重引用符 1） | 5 |
| `a_そのために.csv` | 規則の適用 | 文頭の「そのために」の全件と判断 | 38 |
| `a_結びの節.csv` | 規則の適用 | 論文ごとの結びの節の有無・開始位置・見出しの語 | 305 |
| `b_画像との照合による補正.csv` | 画像との照合による補正 | 出現ごとの補正と本文の補修 | 24 |
| `b_見出し境界.csv` | 画像との照合による補正 | 税大 2 誌の見出しの位置 | 11,684 |
| `b_税大2誌_全頁照合.csv` | 画像との照合による補正 | 税大 2 誌の論文ごとの照合した頁数 | 160 本・14,315 頁 |

画像との照合による補正（`b_画像との照合による補正.csv` の内訳）:

| 補正 | 件数 |
|---|---|
| 頁画像で接続表現でない用法と確かめた出現を除いた（税大論叢 16、税大ジャーナル 1） | 17 |
| 頁をまたぐ引用の内側と確かめた出現を除いた（税法学） | 1 |
| 誤った組になる引用符を、引用符として扱わなかった（税大論叢） | 2 |
| 脚注・柱の混入と欠けた行を、本文で直した（税法学 2 本の 4 か所） | 4 |

## コードだけでは再現できない工程

| 工程 | 内容 | 残っている記録 |
|---|---|---|
| 『税法学』の本文の作成 | AI が PDF の文字層と頁画像から本文を作った。作成に使ったスクリプトの多くは残っていない | 論文ごとの確認記録（リポジトリには入れていない） |
| 税大 2 誌の頁画像との照合 | 規則で作った本文（③）を、AI が全 14,315 頁の画像と全行照らして直した。スクリプトは頁画像の作成と記録の保存だけで、読む作業は含まない | 論文ごとの照合した頁数（`data/decisions/b_税大2誌_全頁照合.csv`）。頁ごとの照合記録と頁画像の SHA-256 はリポジトリには入れていない |
| 規則の決定 | 辞書・位置・除外の規則は著者が決めた。非接続の用法の規則は、候補を AI が文脈ごとに判定した結果をもとにしている | 規則は `recount_core.py` |
| 直接引用の前後の対応 | 直接引用の抽出、引用の種別の付与、前後の文との対応づけは人と AI が行った。作成手順のスクリプトは残っていない | 引用と文 ID の対応表（リポジトリには入れていない） |

『税法学』の脚注の機械マスク（`04_zeihougaku_footnote_mask.py`）は、手元の本文 145 本で、集計に使った脚注除去後の本文と SHA-256 が一致しました。税大 2 誌の本文の自動作成（`03_nta_pdf_to_body.py`）も、照合前の本文 160 本と一致しました。照合で直した後の本文は、このスクリプトからは作れません。
